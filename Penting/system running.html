System Architecture & Dashboard Manual

Dokumentasi lengkap menggabungkan cara Dashboard beroperasi dengan senibina Cloud AI dan Windows Executor Bot.

1. Permulaan Sistem (Startup Sequence)

Proses ini berlaku di Laptop/PC/VPS Windows anda.

[KLIK] start_bot.bat
  |
  v
Memulakan bot_manager.py (Pengurus Induk Utama)
  |
  v
Membaca Dashboard (Supabase) untuk kenal pasti Master & Akaun Klien Aktif
  |
  +------> Spawns 1x master_analyzer.py (Otak / Pembaca Market)
  |
  +------> Spawns Nx executor_bot.py (Tangan / Tukang Trade mengikut Akaun)
  |
  v
Sistem Auto-Restart: Jika mana-mana terminal atau Python crash, 
ia dihidupkan semula dalam 5 saat.

2. Modul Dashboard: API Keys (Peranan AI)

Di halaman API Keys, sistem mengasingkan otak AI kepada 3 peranan utama untuk keselamatan dan penjimatan quota API.

MAIN MODEL

Master Analyzer

Dipasang di tab "Master". AI ini membaca chart XAUUSD setiap 10/30/60 minit untuk menghasilkan keputusan BUY/SELL, berserta TP/SL sasaran.

RISK MODEL

Executor Second Opinion

Ditetapkan khas untuk akaun klien. Bertindak menapis signal dari Main Model. Contoh: "Akaun ini margin kecil, jangan ambil setup Swing ini."

TRADE EVALUATOR

Active Trade Evaluator

Dipanggil setiap 20 minit apabila ada trade floating. Berperanan sebagai "Penasihat" untuk terus Hold, Ubah SL/TP, atau Cut-loss awal (Early Exit).

Nota Penting: Sistem menyokong Dynamic Failover (Fallback). Jika model utama (cth: openai/gpt-oss) gagal atau habis limit, ia automatik melompat ke Fallback Provider di bawahnya.

3. Modul Dashboard: Account Settings

Halaman ini menetapkan parameter trading khusus untuk setiap akaun. Robot di Windows akan sentiasa menarik data ini secara real-time.

A. Master Analyzer MT5 Settings

  • Hanya digunakan oleh "Otak" untuk menyedut data OHLCV & Tick pasaran.
  • TIDAK digunakan untuk membuka apa-apa trade. Akaun demo disarankan.

B. Client Trading Settings (Ammar / Hakim / dsb.)

Setiap klien mempunyai tetapan fleksibel yang dipecahkan kepada tiga gaya trade:

Gaya Lot Size Grid Recovery Trailing & BE
Scalping Lot besar sedikit. Sesuai jika salah arah jangka pendek. Cepat Break-Even, Trailing rapat.
Intraday Lot sederhana. Grid jarak sederhana. BE sederhana, bagi ruang harga bernafas.
Swing Lot kecil. Grid jarak besar. Trailing Stop yang luas (jarak jauh).

C. Global Limits & Filters (Pertahanan Utama Klien)

  • Max Risk % / Max Drawdown %: Jika floating loss melepasi tahap ini, bot tidak akan buka *trade* baru.
  • High-Impact News Action: Boleh disetkan untuk menyekat entry baru atau menutup semua trade hijau sebelum *News* meletup.
  • Hedging Strategy: Kebolehan bot untuk memegang BUY dan SELL serentak (*Locked Position*) jika pasaran ekstrem.
  • Manual Trade Management: Walaupun anda buka trade secara manual di telefon (MT5 bimbit), anda boleh setkan di dashboard agar Bot tolong jagakan SL, TP, dan BE untuk trade manual tersebut!

4. Flow Lengkap (Dari Bacaan AI hingga ke MT5 Terminal)

A. OTAC MEMBACA MARKET (Master Analyzer)
Setiap 10/30/60 Minit, Master tarik data dari Master MT5.
|--> Hantar ke MAIN MODEL AI.
|--> Main Model keluarkan signal: "XAUUSD BUY, SL: 2300, TP: 2320".
|--> Master hantar signal (Broadcast) ke Dashboard (Supabase).

B. TANGAN MENERIMA SIGNAL (Executor Bot)
Executor Bot klien A mengesan ada signal baru di Supabase.
|--> RISK AI dihidupkan untuk check baki Klien A. 
|--> Jika "Lulus", masuk trade menggunakan Lot/Grid dari tetapan Account Settings.
|--> Trade berjaya dibuka di Terminal MT5 Klien A.

C. DUA LAPISAN PENJAGAAN TRADE AKTIF (Floating)
Lapisan 1 (Python) - Setiap 2 Saat:
Executor Bot menyemak tick di MT5 setiap 2 saat. Jika harga kena Virtual SL/TP 
yang ditetapkan di Account Settings, bot cut-loss/take-profit SERTA MERTA.

Lapisan 2 (Evaluator AI) - Setiap 20 Minit:
Master hantar ringkasan trade yang tengah floating ke TRADE EVALUATOR AI.
Evaluator AI menasihati sama ada untuk Hold, Ubah SL/TP, atau Potong awal (Reversal).

5. Modul Dashboard: Live Monitor

Halaman pemerhatian pasif (read-only) yang boleh diakses dari mana-mana peranti untuk melihat "kesihatan" bot.

  • Bot Status Heartbeat: Memastikan laptop/Windows bot anda masih hidup. Jika tulis "Stale", maknanya skrip Python di rumah/VPS anda terputus.
  • Market Signals (Broadcast): Sejarah isyarat AI (beserta Signal ID, Alasan AI, dan Confidence Level).
  • Active Trades: Menunjukkan ticket yang sedang dibuka, arah, Lot, gaya (Scalping/Swing), dan paras Virtual SL/TP semasa.
  • Closed Trades (History): Bukti penutupan trade. Akan tertera Reason (contoh: SL (Profit) untuk Trailing Stop, atau reverse_signal jika Evaluator AI mengesan reversal).
  • Pattern Ranking: Analitik ketepatan Candlestick Patterns. Sistem mengira corak mana (cth: Bullish Engulfing, Tweezer Bottom) yang paling mempunyai Win Rate tinggi dan menyumbang kepada Net Profit terbesar di XAUUSD.

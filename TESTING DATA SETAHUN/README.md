# TESTING DATA SETAHUN

Folder ini menyimpan semua perkara berkaitan backtest / testing data setahun untuk Investment-AI_T.

- `tutorial testing setahun data.md` - cara guna step-by-step.
- `run_yearly_backtest.py` - runner utama.
- `run_yearly_backtest.bat` - one-click runner untuk Windows.
- `research/` - modul collect MT5 history, simulate trade, pattern analytics, dan generate report.
- `reports/` - HTML report profit/loss + pattern analytics.
- `storage/history/` - candle history dari MT5.
- `storage/features/` - dataset indicator + pattern.
- `storage/backtests/` - trades CSV, pattern ranking, lock, state.
- `storage/live/` - live/realtime checkpoint supaya test setahun tidak ulang data yang sudah live.
